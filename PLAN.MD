# План разработки MVP магазина приложений (Android)

## Общая оценка MVP: 3 Epicа (6 недель)

---

## Epic 1. Основа проекта и список приложений
**Длительность:** 2 недели (80 часов)  
**Цель:** Пользователь видит список доступных приложений с базовой информацией.

### Задачи (оценка ≤ 8 часов каждая)

1. **Настройка проекта** (4 ч)
    - Создать Android проект (Kotlin, MVVM, Clean Architecture слои: data/domain/presentation).
    - Подключить зависимости: Retrofit, Room, Coroutines, ViewModel, LiveData/Flow, RecyclerView.

2. **Модель данных приложения** (2 ч)
    - Создать `AppEntity`, `AppModel`, `AppDto`.
    - Описать мапперы между слоями.

3. **Локальный кэш (Room)** (4 ч)
    - Таблица `installed_apps` (id, packageName, versionCode, installDate).
    - DAO: CRUD операции.

4. **API-клиент (мок/бэкенд)** (4 ч)
    - Эндпоинт `GET /apps` (id, название, иконка (URL), описание, рейтинг, размер).
    - Retrofit интерфейс, DTO.

5. **Репозиторий приложений** (6 ч)
    - Получение списка из API с кэшированием в памяти.
    - Объединение с данными об установленных приложениях из Room.

6. **ViewModel для списка** (4 ч)
    - `AppsListViewModel`: загрузка, состояние (loading, success, error).

7. **Экран списка (UI)** (8 ч)
    - RecyclerView + адаптер.
    - ItemView: иконка, название, рейтинг, кнопка "Установить/Открыть".

8. **Загрузка иконок (Coil/Glide)** (2 ч)
    - Отображение иконок из URL.

9. **Обработка ошибок и пустых состояний** (4 ч)
    - Показать Snackbar/Toast, кнопку повтора.

10. **Unit-тесты репозитория и ViewModel** (6 ч)
    - Mockk, корутины-тесты.

---

## Epic 2. Карточка приложения и детали
**Длительность:** 2 недели (80 часов)  
**Цель:** Пользователь открывает карточку приложения, видит подробную информацию.

### Задачи (оценка ≤ 8 часов)

1. **API: детали приложения** (4 ч)
    - `GET /apps/{id}`: скриншоты, версия, размер, разрешения, дата обновления, changelog.

2. **Детальная модель и маппер** (2 ч)
    - `AppDetails` (domain), `AppDetailsDto`.

3. **Репозиторий: метод `getAppDetails(id)`** (4 ч)
    - Кэш в памяти + API.

4. **ViewModel для карточки** (4 ч)
    - `AppDetailsViewModel`: загрузка деталей.

5. **Экран карточки (UI)** (8 ч)
    - Toolbar с названием.
    - Иконка, название, рейтинг, размер, версия.
    - Скриншоты (горизонтальный RecyclerView).
    - Список разрешений.
    - Кнопки: "Установить/Удалить/Открыть".

6. **Навигация между списком и карточкой** (4 ч)
    - Navigation Component, передача ID.

7. **Shared Element Transition** (4 ч)
    - Анимация иконки из списка в карточку.

8. **Офлайн-кэш деталей** (4 ч)
    - Room: таблица `app_details` + срок жизни кэша 24 часа.

9. **Состояния загрузки/ошибки на карточке** (4 ч)
    - Skeleton/ProgressBar, кнопка Retry.

10. **Тесты (ViewModel, репозиторий, мапперы)** (6 ч)
    - Написание Unit-тестов с использованием Mockk
---

## Epic 3. Установка и удаление приложений
**Длительность:** 2 недели (80 часов)  
**Цель:** Пользователь может устанавливать и удалять приложения, видит прогресс.

### Задачи (оценка ≤ 8 часов)

1. **Менеджер установок (Service/UseCase)** (8 ч)
    - Скачивание APK из URL (временная папка).
    - Запрос на установку пакетов (`ACTION_INSTALL_PACKAGE`, разрешение в манифесте).
    - Обработка результата (успех/ошибка).

2. **Менеджер удаления** (4 ч)
    - `Intent(ACTION_DELETE)` + `packageName`.
    - Callback через Activity Result API.

3. **Обновление статуса установленных приложений** (6 ч)
    - BroadcastReceiver/ContentObserver на `ACTION_PACKAGE_ADDED/REMOVED`.
    - Синхронизация с Room (`installed_apps`).

4. **UI: прогресс установки** (6 ч)
    - Notification с прогрессом (DownloadManager или ForegroundService).
    - Либо диалог внутри приложения.

5. **ViewModel: установка/удаление** (4 ч)
    - События (одноразовые) для навигации к системному установщику.
    - Состояния кнопки: "Установить", "Открыть", "Удалить".

6. **Блокировка действий во время установки** (4 ч)
    - Кнопка "Установка..." (disabled), показ индикатора.

7. **Кнопка "Открыть" для установленных приложений** (4 ч)
    - Запуск приложения через `packageManager.getLaunchIntentForPackage`.

8. **Обработка ошибок установки** (4 ч)
    - Недостаточно места, APK повреждён, запрет неизвестных источников — показать диалог с инструкцией.

9. **Интеграционные тесты установки (эмулятор)** (8 ч)
    - Проверить цепочку: установка → обновление БД → кнопка "Открыть".

10. **UI-тесты** (8 ч)
    - Сценарии: установить приложение → вернуться в список → увидеть "Открыть".
    - Удалить → статус сменился на "Установить".
